## Overview

This project provides an implementation of **Genetic Algorithms**, demonstrating how evolutionary principles can be applied to solve complex optimization problems. The repository includes theoretical explanations and hands-on examples, from basic mathematical function optimization to real-world applications like cricket team selection. It was developed as part of a lab assignment for Artificial Intelligence lab.

## How to Use

### Basic Setup

```bash
git clone <repository-url>
cd genetic-algorithm
pip install -r requirements.txt
```

### Running the Notebook

```bash
jupyter notebook  Genetic_Algorithm.ipynb
```

Navigate through the cells to explore:
- Theoretical background on GA
- Step-by-step algorithm walkthrough
- Practical implementation examples
- Performance analysis and results

## Requirements

- Python 3.7+
- numpy
- matplotlib
- pandas
- jupyter (for notebooks)

Install dependencies:

```bash
pip install numpy matplotlib pandas jupyter
```
